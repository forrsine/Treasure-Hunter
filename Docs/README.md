| 文档 | 用途 | 事实来源 |

## 命名约定

- 游戏对外名称统一为《宝藏猎手》。
- `TreasureHunterArchitecture`、`TreasureHunter.Server`、协议类和 Unity Editor 菜单属于既有技术标识。
- 技术标识只有在单独执行全项目重命名、完成编译和资源引用回归时才应修改。
- 仓库目录名暂时保留为 `Treasure-Hunter`，避免影响本地路径、解决方案和外部链接。

## 更新规则

1. README 和当前策划案只能写已经实现或明确标记为规划的内容。
2. 每完成一个功能，在 `ProjectLearningNotes.md` 末尾追加记录。
3. 新增长期数据时，同步更新架构文档和存档边界。
4. 没有真实测试结果或 Profiler 数据时，不填写通过率、FPS、GC 和优化百分比。
5. 历史策划案只增加归档说明，不反向伪装成当前完成状态。
